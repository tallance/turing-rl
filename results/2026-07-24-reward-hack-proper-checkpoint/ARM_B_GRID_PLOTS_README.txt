Plot construction
-----------------
The 9B runs use 7 sampled prompts x 4 rollouts, producing 28 reward rows per
optimizer update. The aggregate plots timestamp-sort rows and chunk by 28.
Per-example plots group by (user_id, post_id, target_idx), timestamp-sort each
group, and chunk by 4 rollouts. Their x axis therefore counts prompt appearances,
not globally aligned optimizer updates.

Score rule:
  win: turing_judge_score_raw >= 5
  tie excluded: turing_judge_score_raw == 4
  parse failure excluded: turing_judge_score_raw is 0 or null
