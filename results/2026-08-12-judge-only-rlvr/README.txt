REPRODUCTION
------------
Not reproducible as configured: the thinking defect was fixed after these
runs. To reproduce the ABLATION exactly, submit from source_sha above, which
predates the fix. To run the corrected configuration, use current main and
set MODE=full; thinking is then resolved from the config.

  scripts/cluster_launch.sh --dependency-profile training \
    --run-root <absolute-cluster-run-root> \
    --env JUDGE_MODEL_PATH=Qwen/Qwen3.5-9B \
    --env JUDGE_REWARD_ARM=graded --env MODE=full \
    --env HF_HUB_OFFLINE=1 --env RL_CKPT_DIR=<run-root>/checkpoints \
    --env EXTRA_OVERRIDES="trainer.total_epochs=1 trainer.test_freq=13 \
      trainer.save_freq=26 trainer.val_before_train=True" \
    scripts/launch_judge_train.sh
